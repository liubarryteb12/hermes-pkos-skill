# 文案风格模板注册库（voice-styles:1）

> 2026-09-05 用户裁定：文案出口统一走 wenzhang，但风格可以不同——不同文案风格的撰写模板与机制注册于此，备用。
> 机制与 my-voice 个人档案（`_PKOS/assets/my-voice.md`）共存：**个人档案永远优先**（真实文风数据），风格模板只补结构骨架；两者冲突时以 my-voice 为准。

## 叠加机制

```
选题单 style_hint（28-pkos-topic 建议）→ 本表查 style_id → 取结构骨架/开头收尾模板
  → 叠加 my-voice 档案（句式/节奏/词汇偏好，优先级更高）
  → voice-overrides lint 阈值仍以 my-voice 的 JSON 块为单一来源
```

- style_hint 缺省 = 纯 my-voice 模式（现状不变）。
- 一个模板 = `style_id` + 七字段（见下），注册进本表即生效；新风格按同格式追加，不改机制。

## 模板字段规范

每条风格模板必须含：`适用场景 / 结构骨架 / 句式特征 / 开头模板 / 收尾模板 / 长度区间 / 禁则`。

## 已注册风格

### style: 保姆级教程
- **适用场景**：新功能/新工具首发期教程（搜索红利期），步骤可完全兑现。
- **结构骨架**：痛点一句 → 前置条件清单 → 编号步骤（每步=操作+截图位+预期结果）→ 常见报错 3 例 → 进阶玩法 1 条。
- **句式特征**：祈使句为主；每步首句动词开头；数字编号锚定。
- **开头模板**：「如果你也遇到过 <痛点>，这篇 10 分钟带你跑通。」
- **收尾模板**：「跑到哪一步卡住了，评论区贴报错，我补进常见报错里。」
- **长度区间**：1200-2000 字。
- **禁则**：不跳步；不写「很简单」「轻松」贬低读者；截图位必须留。

### style: 亲测复盘
- **适用场景**：我+代价+收获类选题；有真实使用数据/踩坑记录。
- **结构骨架**：结论先行（一句话收获+一句话代价）→ 背景（为什么做）→ 过程关键节点 3 个（各带数据）→ 三个坑与解法 → 复用清单。
- **句式特征**：判断句起手；数字锚定（天数/条数/耗时）；少形容词。
- **开头模板**：「我用了 <时长> 跑通 <事情>，先说结论：<收获>，但代价是 <代价>。」
- **收尾模板**：「这套东西我还在养，下个月复盘 <下一节点>。」
- **长度区间**：1500-2500 字。
- **禁则**：不编数据；代价不能略写（只写收获=广告感）。

### style: 横评选型
- **适用场景**：对比站队类选题；有可复现的同任务实测。
- **结构骨架**：选型问题定义 → 评测维度表 → 逐项对比（每项一胜者）→ 按读者场景给选型结论（3 类人群）→ 评测方法附录用（可复现）。
- **句式特征**：表格密度高；每节末一句「所以谁该选它」。
- **开头模板**：「<A> 和 <B> 吵了半年，我拿同一个任务让它们打了一周。」
- **收尾模板**：「你的场景是哪类？评论区说，我补测。」
- **长度区间**：1800-3000 字。
- **禁则**：维度必须先于结论；不给无数据的高低评价。

### style: 热点快评
- **适用场景**：时效池选题（热点窗口 ≤2 周）；信号来自 29-pkos-trend 情报单。
- **结构骨架**：事件一段（来源+证据）→ 对读者意味着什么 → 1 个可执行动作 → 时效声明。
- **句式特征**：短段（≤100 字）；信息密度优先；无铺陈。
- **开头模板**：「<事件>，来源 <出处>。跟你有关系的是这一条：」
- **收尾模板**：「窗口就 <N> 天，要做趁早。」
- **长度区间**：600-1000 字。
- **禁则**：无热度证据的事件不写；不做无依据的预测；不堆砌多个热点（一篇一个）。
