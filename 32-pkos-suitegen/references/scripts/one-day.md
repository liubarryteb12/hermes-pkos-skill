# 剧本模板：一日 24 小时（one-day）

> 叙事骨架：从晨到夜的时段推进。适合生活/居家/人物日常主题。

## 骨架

```
第1场 黎明（晨光初现，室内微光）
  ↓
第2场 清晨（窗光，清醒）
  ↓
第3场 上午（日常活动，明快）
  ↓
第4场 正午（顶光，明亮）
  ↓
第5场 午后（斜光，慵懒）
  ↓
第6场 黄昏（暖调，过渡）
  ↓
第7场 入夜（灯光，私密）
  ↓
第8场 深夜（最暗，安静）
```

## 每场要素

`时段 / 光源 / 机位 / 主体动作 / 情绪 / 色彩 / 衔接`

## 张数

- 最小 8 = 8 时段各一场
- 最多 22 = 每时段可拆 2-3 个机位/动作
