# 剧本模板：城市漫游（city-walk）

> 叙事骨架：空间流动、场景递进、时间流变。适合街拍/都市主题。
> 每场 = 一个街景/时段，情绪与光线随漫游推进。

## 骨架

```
开场（城市晨光/地标，确立空间）
  ↓
街巷（窄街/人流，中近景）
  ↓
市集/广场（热闹，色彩丰富）
  ↓
转角/巷弄（安静，光影对比）
  ↓
河畔/天台（开阔，远景）
  ↓
夜晚街区（霓虹/灯流）
  ↓
收束（回到起点/夜空，闭环）
```

## 每场要素

`场景 / 时段 / 机位 / 主体 / 光线 / 情绪 / 衔接`

## 张数

- 最小 8 = 开场+6 街景+收束
- 最多 22 = 每街景可拆不同机位/人流疏密
