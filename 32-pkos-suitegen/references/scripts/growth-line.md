# 剧本模板：成长线（growth-line）

> 叙事骨架：起点 → 挫折 → 突破 → 升华。适合人物/角色蜕变主题。
> 填表时 AI 把每格变成具体场景，产出 `<套图ID>/script.md`。

## 骨架

```
开场锚（确立人物/世界，安静）
  ↓
第1场 起点：现状/日常，情绪平稳
  ↓
第2场 裂痕：微小失衡出现，光色微变
  ↓
第3场 挫折：明显挫败，色调转冷/低
  ↓
第4场 沉底：情绪谷底，画面最暗
  ↓
第5场 转机：一丝光，动作转变
  ↓
第6场 突破：决定性时刻，构图张开
  ↓
第7场 升华：蜕变完成，明亮/暖调
  ↓
收束（回望起点，形成闭环）
```

## 每场要素

每场必须写：`场景 / 机位 / 主体动作 / 情绪 / 关键道具 / 与上一场衔接`

## 张数

- 最小 8 张 = 开场+6 场+收束
- 最多 22 张 = 每场可拆 2-3 个机位变化
