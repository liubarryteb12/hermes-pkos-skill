## 登记方法

新增风格时在本表加一行，并创建 `references/styles/<style-id>/`：
```
<style-id>/
├── SKILL.md   # 风格DNA：特征/审美词块/负向/适用场景
└── seeds/     # 优秀素材种子（可空，喂种子后累积）
```

## 进化记录字段

- `种子数`：seeds/ 内文件数（喂一条 +1）
- `进化记录`：乙=日常喂种子日期；甲=skillopt 批量训练日期
