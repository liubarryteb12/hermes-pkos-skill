# profile.md —— 纸墨主题写作规范（给 AI 读的约束文档，不是 CSS）

你正在为「纸墨」主题撰写内容。这是一个中文长文阅读版式：安静的图书馆气质。
以下约束与 theme.json 同源，冲突时以 theme.json 为准。

## 内容结构约束

1. 一篇一个 `#` 主标题（居中渲染），3–6 个 `##` 章节；
2. 每章 ≤4 段正文；段落 2–5 句；禁止三段以下就换章节；
3. `>` 引用块只用于**原文引用或关键命题**，全文 ≤3 处——它是卡片底色的视觉锚点；
4. 学习路径类文章用有序列表表达步骤，序号会渲染为朱砂色（accent 锚点），
   因此**全文 ol 至多 2 个**；
5. 表格用于对照信息（斑马纹自动渲染），不用于叙事。

## 语言约束

- 中文为主，术语首次出现给英文原词；
- 禁止 theme.json `avoid` 列表中的全部气质项（渐变词、emoji、营销动词）；
- 每个章节的第一句必须能独立成立（读者跳读时靠它导航）。

## 信息保留比例

本主题默认承接 router 类型 `学习路径` → **保留度 ≈90%**（tutorial 档）：
源条目的事实、数字、人名不得丢失；允许重排顺序与压缩重复论证。

## 渲染分工

你只产出 Markdown 中间表示（槽位语义已由 markdown 结构隐含），
HTML 装配全部由 render.py 从 theme.json 取组件完成。禁止手写 HTML/CSS/内联样式。
