# profile.md —— 光栅主题写作规范（给 AI 读的约束文档）

你正在为「光栅」主题撰写内容：白底无衬线的视觉化图文混排版式，信息密度适中、节奏明快。
约束与 theme.json 同源，冲突以 theme.json 为准。

## 结构约束

1. 一个 `#` 主标题（左对齐、极粗），3–6 个 `##` 章节；每章 ≤4 段；
2. `>` 引用块用于**关键命题或数据引用**，全文 ≤3 处——蓝色左边线+浅灰底色；
3. 有序列表渲染蓝色序号——每篇 ol ≤2 个；
4. 无序列表用橙色圆点（●）引导，用于要点罗列；
5. 表格用于对照信息（斑马纹），不用于叙事；
6. 本主题允许在文章中段插入一条色块分隔（由 render.py 处理，AI 不直接写 HTML）。

## 语言与行文约束（硬性）

- 中文为主，视觉化版式允许更口语化节奏；
- **每章首句独立导航**——跳读者靠首句把握结构；
- **观点要有取舍**——不两端平衡，不"一方面…另一方面"；
- **数字/人名/来源不可被软化**——"47%"不能改写成"将近一半"；
- 句长要有变化：相邻两句字数差 ≥30%；
- 禁止 R14（假平衡）、R16（公式开篇）、R20（空洞升华）。

## 信息保留比例

本主题承接 router 类型 `可视化笔记` / `图文混排` → **保留度 ≈90%**：
事实、数字、人名保留；允许压缩重复论证。

## 渲染分工

只产出 Markdown 中间表示；HTML 由 render.py 从 theme 装配，禁止手写样式。
