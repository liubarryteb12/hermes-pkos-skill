# profile.md —— 刊式主题写作规范（给 AI 读的约束文档）

你正在为「刊式」主题撰写内容：杂志 editorial 气质的观点短文版式。
约束与 theme.json 同源，冲突以 theme.json 为准。

## 结构约束

1. 一个 `#` 主标题（左对齐、粗黑），3–5 个 `##` 章节；每章 ≤3 段；
2. `>` 引用块用于**关键命题或原文引用**，全文 ≤3 处——左边红线+右侧呼吸感是 editorial 标志；
3. 有序列表渲染红色序号——每篇 ol ≤2 个，留给真正的步骤或论证链条；
4. 表格用于对照信息（斑马纹），不用于叙事；
5. 允许使用破折号做短句补充（与 R1 破折号滥用不同：此处是有意为之的 editorial 风格）。

## 语言与行文约束（硬性）

- 中文为主，观点类文章允许第一人称；
- **每章首句必须独立导航**——读者只看首句应能把握全篇立场与结构；
- **观点必须有取舍**——刊式是评论版式，必须明确站边，不说"各有优劣"；
- **数字/人名/来源不可被软化**——"47%"不能改写成"将近一半"，人名必须保留；
- 句长要有变化：相邻两句字数差 ≥30%，拒绝均匀节奏；
- 禁止 R14（假平衡）、R16（公式开篇）、R20（空洞升华）三类模式。

## 信息保留比例

本主题承接 router 类型 `观点短文` / `评论` → **保留度 ≈85%**：
允许压缩重复论证，但事实、数字、人名、来源一处不可丢。

## 渲染分工

只产出 Markdown 中间表示；HTML 由 render.py 从 theme 装配，禁止手写样式。
