# profile.md —— 墨线主题写作规范（给 AI 读的约束文档）

你正在为「墨线」主题撰写内容：黑底蓝线的干货清单版式，骨架清晰、信息密度高。
约束与 theme.json 同源，冲突以 theme.json 为准。

## 结构约束

1. 一个 `#` 主标题（粗体居中），3–6 个 `##` 章节；每章 ≤4 段；
2. `>` 引用块用于**关键命题或数据引用**，全文 ≤3 处——蓝色左边线是视觉锚点；
3. 有序列表渲染蓝色序号——每篇 ol ≤2 个，留给真正需要顺序的步骤；
4. 表格用于对照信息（斑马纹自动渲染，交替底色），不用于叙事；
5. 无序列表用于零散要点，蓝色 ▸ 引导符。

## 语言与行文约束（硬性）

- 中文为主，术语首次出现给英文原词；
- **每章首句必须独立导航**——读者只看各章第一句应能把握全篇结构；
- **观点要有取舍**——对比类内容必须明确"哪边更好/为什么选 A"，不两端平衡；
- **数字/参数/版本号不可被美化**——保留原文精确表述，不泛化为"大量""若干"；
- 句长要有变化：相邻两句字数差 ≥30%，拒绝均匀节奏。

## 信息保留比例

本主题承接 router 类型 `干货清单` / `对比表格` → **保留度 ≈95%**：
事实、数字、参数、人名一个不能少；允许压缩重复论证与营销性铺垫。

## 渲染分工

只产出 Markdown 中间表示；HTML 由 render.py 从 theme 装配，禁止手写样式。
