# 规则卡：file-pdf（本地 PDF）

## 适用
intake 分拣单 `route_to: card-file-pdf`、`detected_format: text-pdf`。扫描型/加密型在 intake 已被拒收，不会到达本卡。

## 工序
1. **文本层提取**：优先 pandoc 不支持 PDF——用 Python 侧确定性提取（pypdf 类零依赖实现有困难时，用 intake probe 的 BT/ET 文本操作符抽取，带页码锚点）。
2. **页码锚点**：每页正文前插 `<!-- pkos:page N -->` HTML 注释锚点（Obsidian 预览不可见，机读可定位），引用格式「(p.N)」可溯源。
3. **拆章阈值**：probe 报告页数 >50 页时不整本硬塞——产出**按书签/章级标题的拆章建议清单**（每章一个待入库条目），交用户勾选后再逐章入库。
4. **验收 gate**：总字符 ≥500 且无乱码；每页字符数异常（<10）的页在报告中标注「可能为图版页」。
5. **去重 → 入库**：同 file-md 第 4-5 步；source 用 `file:<sha12>`。

## 已知坑
- 双栏论文顺序会乱：标注「栏序可能错位」进 INFO，不自动重排（宁真勿顺）。
- 公式提取必然失真：保留原样并 INFO 说明，不假装可读。
