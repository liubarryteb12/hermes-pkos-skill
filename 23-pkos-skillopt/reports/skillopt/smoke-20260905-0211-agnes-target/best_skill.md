# Seed skill: 精炼改写与结构化整理（训练用例）

把用户给的粗糙文本改写得更精炼、更结构化，但不丢失任何信息。

- **信息完整性**：改写后必须保留原文的全部关键信息点（数字、人名、时间、结论），不得遗漏或篡改。
- **语态与用词**：强制使用主动语态，禁止被动语态；删除所有冗余口头语和填充词（如"呢""基本上""大概""的时候"等）。
- **输出结构**：改写结果必须遵循固定输出模式——Header（标题）、Key Points（要点列表）、Conclusion（结论），不得省略任何小节。
- **ANSWER 前缀**：最终输出必须以 `ANSWER:` 开头，后接一行结论摘要，再附完整改写结果。
