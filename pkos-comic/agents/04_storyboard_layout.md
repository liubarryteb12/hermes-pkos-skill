# Agent 04 - Storyboard Layout (叙事节奏 + 镜头语言)

## 职责

按宫格数（4 宫/6 宫）+ 故事大纲（起承转合），把每格排布成节奏清晰的镜头序列。

## 4 宫格节奏（v0 锁死）

| 格 | 景别 | 作用 |
|---|---|---|
| 第 1 格 | 远景 / 全景 | 建立环境 + 主角初始状态 |
| 第 2 格 | 中景 / 特写 | 矛盾触发 / 痛点呈现 |
| 第 3 格 | 中近景 / 局部 | 情绪转折 / 意外 |
| 第 4 格 | 全景 / 远景 | 收尾点题 / 幽默反转 |

## 6 宫格节奏（v0 锁死）

| 格 | 景别 | 作用 |
|---|---|---|
| 第 1 格 | 远景 / 全景 | 建立环境 + 主角疲惫/初始状态 |
| 第 2 格 | 中景过渡 | 进入新场景 / 动作切入 |
| 第 3 格 | 特写 / 细节 | 感官与情绪放大 |
| 第 4 格 | 多视角 / 双人 | 他人介入 / 关系互动 |
| 第 5 格 | 群像 / 俯视 | 共鸣高潮 / 情绪接住 |
| 第 6 格 | 远景背影 / 开阔画面 | 背影离去 / 释怀升华 |

## 输入

```yaml
grid: "6-grid"
plot_outline:
  起: "晚上 11:30, 小满加完班走出写字楼, 地铁停了, 进便利店"
  承: "店里暖光/关东煮/嗡嗡声, 疲惫卸下"
  转: "意外看到阿鹿和周姐也在"
  合: "三人喝完热饮出门, 小满觉得 PPT 不那么沉了"
characters: [小满, 阿鹿, 周姐]
art_style: "healing"
```

## 输出（分镜主表骨架）

```yaml
panels:
  - panel: 1, row: 1, col: 1
    scene: "起. 写字楼门口, 小满走出来"
    shot: "中景(膝盖以上), 背后平视"
  - panel: 2, row: 1, col: 2
    scene: "起. 便利店门口, 推门, 暖光涌出"
    shot: "中景(腰部以上), 侧面 45 度"
  - panel: 3, row: 2, col: 1
    scene: "承. 店内关东煮柜台, 蒸汽模糊脸"
    shot: "中景(胸部以上), 平视"
  - panel: 4, row: 2, col: 2
    scene: "转. 收银台方向, 阿鹿+周姐在窗边"
    shot: "中景, 前景侧面/后景正面"
  - panel: 5, row: 3, col: 1
    scene: "转/合. 三人同桌, 窗开始下雨"
    shot: "俯视 30 度, 焦点在三人面部"
  - panel: 6, row: 3, col: 2
    scene: "合. 门口, 三人撑伞离开"
    shot: "远景(全身), 背后平视, 三人构图(中左右)"
```

## 节奏自检（出图前过一遍）

- 6 宫的"叙事节奏"按 1-2 起 / 3 承 / 4-5 转 / 6 合 推进
- 情绪曲线合理（不要"格 3 在哭, 格 4 在大笑"）
- 每格都服务 plot_outline（不跑题）
- 完整 prompt 长度 ≤ 600 词（超过 600 模型会丢信息）

## 不做

- 不写英文 prompt（Agent 05 做）
- 不写中文对白（脚本主表层做）
- 不出图
