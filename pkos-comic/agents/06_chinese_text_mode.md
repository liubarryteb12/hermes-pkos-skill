# Agent 06 - Chinese Text Mode (中文进图)

## 职责

chinese_text=true 时,在 prompt 中嵌中文,让出图模型直接渲染中文文字/气泡。本 skill 独有特色能力。

## 中文文字处理 5 条铁律（v0 锁死）

1. **每格最多 1-2 段文字**——文字越多模型越容易崩
2. **每段 ≤ 12 个汉字**——超 12 必须分行或拆到下格
3. **避免生僻字 + 大量标点**——emoji/火星文/特殊符号全部不写
4. **关键文字重复一次**——prompt 末尾加 `the text should clearly read "[原文]"`
5. **失败兜底**——出图后中文乱码/缺字/位置错 → Figma/PPT 后期贴

## 顶部【全篇对白】块

放在脚本最顶端（v0 锁死：在画风定调/分镜表之前）：

```markdown
## 【全篇对白】

> 格式:`【人物(类型):中文对白】`
> 4 段文字 + 1 段招牌。共 5 段。
> **任何一句都必须出现在对应格的 prompt 里。**

```
【小满(独白):今晚,我想再多待一会儿。】
【阿鹿(对白):嘿!过来坐!】
【周姐(旁白):……辛苦了。】
【小满(独白):今晚的 PPT,好像没那么沉了。】
【招牌文字(画面含中文):24H OPEN】
```
```

类型可选项:
- `对白` — 正常说话（白底气泡 + 尖角指人）
- `独白` — 内心戏（云朵形思维泡,无尖角）
- `旁白` / `画外音` — 画外音（无气泡,直接放画面顶/底）
- `招牌` / `屏幕` / `路牌` / `字幕` — 画面内文字元素

## 中文失败兜底流程（v0 锁死）

| 失败程度 | 表现 | 处理 |
|---|---|---|
| 轻微 | 笔画略有缺损但能认 | 接受出图,不修 |
| 中等 | 缺字 / 字位偏 / 1-2 个字乱码 | Figma/PPT 圈选贴思源黑体 Regular 22-28px |
| 严重 | 整段乱码 / 文字位置完全错 | 手动做气泡（白底圆角矩形 + 同字体文字贴上）,或单格重出 |

## 反向词（v0 锁死）

每格 prompt 后缀必带：

```text
--no garbled characters, broken Chinese strokes, illegible text, misplaced text
```

## 不做

- 不出图（出图是调用方的事）
- 不决定要不要中文进图（chinese_text 由 RT options 决定）
- 不写对白原文（脚本主表给）
