# 审美预设库（第五段 · Axx）—— 五段命名体系的灵魂

> 命名体系：母题(Mxx) - 子题(Sxx) - 风格(Fxx) - 用途(Uxx) - **审美预设(Axx)**
> 前四段解决「画什么、怎么画、干什么用」，第五段 Axx 解决「以什么审美秩序去画」——同一组结构词配不同 Axx，成片气质完全不同。
> 每个预设 = 色彩秩序 + 光影偏好 + 质感取向 + 情绪基调 + 必写英文质感词，可直接拼进正向提示词。

## 真人摄影类审美

### A01 清透生活流（日系写真审美）
- 色彩：低饱和、奶白/薄荷/浅灰蓝、肤色暖粉
- 光影：窗边散射光、轻微过曝的空气感、无硬阴影
- 质感：真实毛孔、轻微噪点、手机随手拍、反磨皮
- 情绪：松弛、干净、日常亲密
- 质感词：`Fujicolor Pro 400H tone, soft diffused natural sunlight, fine film grain, airy vibe`
- 适配风格：写实生活感 / CCD / 私房

### A02 冰白高级流（韩系冷调精修审美）
- 色彩：冰蓝白+黑+冷肤色+少量粉红、cool cyan-white grading
- 光影：high-key soft lighting、低光比、面部阴影极浅
- 质感：高亮柔润精修但保留面部结构、无 bloom 无 halation
- 情绪：慵懒、戏谑、都市冷感
- 质感词：`cool environment + warm-neutral skin separation, high-key soft lighting`
- 适配风格：COS 广角 / 制服丝袜 / 直播感

### A03 电影晨暮流（晨暮居家审美）
- 色彩：香槟/琥珀/深棕暗部、暖调低照度
- 光影：单一窗光源斜射、明暗过渡电影感、轮廓光勾边
- 质感：真实皮肤高光带、缎面丝绸反光、浅景深奶油虚化
- 情绪：私密、慵懒、刚醒的松弛与疏离
- 质感词：`cinematic warm low-key, soft highlight roll-off on skin, film-like bloom`
- 适配风格：居家光影 / 床沿窗边 / 酒店客房

### A04 胶片复古流（CCD/一次性胶片审美）
- 色彩：2000s 数码暖白/奶油色调、轻微偏色
- 光影：直闪或逆光 bloom、水汽柔焦
- 质感：fine grain、light leak、highlight bloom、低清感
- 情绪：怀旧、甜、随手记录
- 质感词：`soft-glow CCD portrait, 2000s digicam aesthetic, disposable film camera, light leak`
- 适配风格：CCD / 泡泡浴 / 野餐约会

### A05 冷峻空灵流（雾山清冷审美）
- 色彩：褪色绿灰、蓝青雾气、暖象牙肤色做对比
- 光影：漫射阴天日光、均匀柔光、冷蓝灰+暖肤高光
- 质感：胶片 bloom、奶油虚化、皮肤瓷感但保留纹理
- 情绪：空灵、磁性、邀请与羞涩的张力
- 质感词：`muted green-grey landscape, soft teal mist, warm ivory skin, film-like blooming`
- 适配风格：户外清冷 / 银发雾山 / 草甸

## 二次元/插画类审美

### A06 极简软赛璐璐流（网络二次元 Pin-up 审美）
- 色彩：大面积平涂、明快但少色数、皮肤转折轻渐变
- 光影：无真实摄影光影、soft cel shading、阴影层级少
- 质感：clean lineart 黑色细描边、内部结构线极少
- 情绪：Ara Ara / smug、慵懒自信微狡黠
- 质感词：`clean lineart, crisp anime linework, flat color dominant, soft cel shading, minimal soft shading`
- 适配风格：Pin-up / 服装设定图 / 角色立绘

### A07 CG 半写实流（游戏 CG 审美）
- 色彩：冷蓝环境+淡紫霓虹+肤色柔润
- 光影：侧逆光+Bloom+体积雾、蓝紫光轨
- 质感：AAA 渲染、丝滑长发、真实丝绸材质、皮肤细腻
- 情绪：清冷忧郁、梦幻疏离
- 质感词：`AAA game character rendering, soft bloom, volumetric fog, 35mm cinematic lens`
- 适配风格：赛博窗边 / 游戏 CG / 幻想 CG

## 平面设计类审美

### A08 瑞士网格流（国际主义平面审美）
- 色彩：奶灰白大面积+黑+5% 柠檬黄焦点
- 光影：主体极柔化（磨砂/失焦）与文字极锐利对撞
- 质感：印刷海报感、无衬线小字、非对称平衡、大留白
- 情绪：理性、克制、美术馆级
- 质感词：`Swiss International Typographic Style, large negative space, sharp typography vs soft photography`
- 适配风格：观念海报 / 文化节海报 / 展览主视觉

### A09 日式编辑流（巨字海报审美）
- 色彩：2-4 主色系、允许荧光/朱红/青绿冲突组合
- 光影：不影响摄影主体，版式主导
- 质感：Typography 参与构图、巨大标题出界/压图/被遮挡、纸张纤维
- 情绪：编辑感、强张力、乱中有序
- 质感词：`Editorial Graphic Design, typography as composition, oversized display type, micro typography`
- 适配风格：巨字海报 / 文化海报 / 杂志封面

### A10 手作工艺流（转绘材质审美）
- 色彩：从原图提纯、主色+邻近色+少量对比色
- 光影：柔和短投影（实体感）、无强反差
- 质感：珐琅/金箔锤纹/积木哑光/纸雕层叠——材质即风格
- 情绪：收藏感、精致、治愈
- 质感词：`enamel fill + metal separator, hammered gold foil texture, matte modular blocks, layered paper-craft`
- 适配风格：转绘海报 / 冰箱贴 / 徽章

## 使用规则

1. **组合公式**：`Mxx-Sxx-Fxx-Uxx-Axx` 五段全填；正向提示词 = 风格文件的结构模板 + Axx 的色彩光影质感词块。
2. **一键换审美**：同一结构模板换 Axx 编号即出新作品——如「私房床沿」配 A03 是晨暮私房，配 A04 变 CCD 随手拍，配 A02 变韩系冷调。
3. **混血规则**：最多双预设混血（如 A01+A04 清透生活×胶片），主预设占 70% 描述量，次预设只借光影或色彩单一维度。
4. **冲突禁配**：A08/A09（平面类）不与 A01-A05（摄影类）混——版式审美与摄影审美叠加会打架。
5. **扩展**：新审美先在库里登记编号和五要素，再投入使用。
