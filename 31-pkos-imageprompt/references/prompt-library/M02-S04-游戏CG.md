# M02-S04 游戏CG · 20 题词系列

## F01 赛博窗边（技法基础：八段式+CG 环境）

**风格锚点**：9:16，3D 半写实游戏 CG 风，高层公寓落地窗边，窗外深夜赛博都市（摩天楼/薄雾/霓虹光轨），冷蓝环境光+淡紫霓虹反射+柔和侧逆光，AAA game character rendering, soft bloom, volumetric fog，35mm 电影镜头，清冷忧郁。

1. `M02-S04-F01-U03-A07` 成年女性角色银白长发坐落地窗边地毯，白丝绸衬衫黑色蕾丝内搭，赤足侧坐回望，窗外雨夜都市蓝紫光轨，冷蓝环境光，AAA 渲染丝滑发丝。
2. `M02-S04-F01-U05-A07` 同角色系列：她站在窗前手贴玻璃，全息界面倒映在玻璃与瞳孔，机械臂咖啡机入画，赛博生活感。
3. `M02-S04-F01-U02-A07` 封面：落地窗前剪影——她与城市天际线重叠，室内只有屏幕蓝光照亮轮廓，右侧留标题空间，科幻片海报感。
4. `M02-S04-F01-U06-A07` 试验：窗玻璃上的雨滴、霓虹倒影与她指尖触碰玻璃的特写，虚实双层。

## F02 机械义肢（技法基础：八段式+科幻设定）

**风格锚点**：4:5，半写实 CG，人物与机械部件融合（义肢/接口/能量纹路），金属与皮肤材质对比刻画，工作室冷光+能量蓝光，机库/实验室背景，Hard surface 细节。

5. `M02-S04-F02-U03-A07` 成年女性角色机械左臂特写姿态，肩部接口能量纹路微光，飞行服半褪系腰间，机库冷白光+暖橙警示灯，坐工具箱上缠绷带。
6. `M02-S04-F02-U05-A07` 同角色：整备中——悬浮机械臂为她校准义肢，全息数据环绕，她闭眼忍耐，汗珠反光。
7. `M02-S04-F02-U02-A07` 封面：义肢手掌与人类手指交扣特写，能量纹路沿手臂亮起，黑暗背景仅两处光源，极简海报。
8. `M02-S04-F02-U06-A07` 试验：义肢关节拆解悬浮排列（爆炸图式），工具与备用能量芯，等距视角。

## F03 奇幻战场（技法基础：八段式+史诗 CG）

**风格锚点**：2:3 或 9:16，写实 CG 战场史诗，魔法光效与物理烟尘并存，破败城堡/巨龙剪影/坠落的旗帜，逆光+体积光 god rays，战损细节，电影级构图。

11. `M02-S04-F03-U03-A07` 竖版：城墙垛口她搭箭拉弓，金瞳发光，箭尖凝聚风魔法旋涡，身后战旗猎猎。
12. `M02-S04-F03-U06-A07` 试验：断裂的法杖、碎裂水晶与飘落羽毛的战场遗迹静物，体积光穿过。
