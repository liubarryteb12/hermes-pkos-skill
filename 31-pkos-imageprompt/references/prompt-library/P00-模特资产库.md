# P00 模特资产库 v2（可复用人物锚点系统 · 已过 S00 安全层）

> 思路：把人物写成一份固定的「锚点合同」，与风格/审美解耦。模特锚点 × 任意 Fxx 风格 × 任意 Axx 审美 = 同一个人在不同作品里。
> 库内方法论验证：@VoxcatAI 换装公式、写真 Skill 的「身份图管她是谁、写真参考管怎么拍」、U05 系列一致性规则——三流归一。
> v2：全部锚点已按 S00 消毒——身材写整体印象与动态，不写部位尺寸；气质写情绪语言，不写欲望词族。

## 一、锚点合同结构（写一次，处处引用）

每个人模 = 六层锚点，**前四层是身份层（跨图锁死），后两层是可变层（随作品轮换）**。

```
Pxx 模特锚点合同
├─ ① 骨架层：年龄/身高/体态整体印象 —— 跨图不变
├─ ② 面容层：脸型/眼型/眉/鼻/唇/肤质/痣 —— 跨图不变
├─ ③ 毛发层：发色发质/基础发型 —— 颜色发质不变，扎起披下可变
├─ ④ 标志层：固定饰品/固定小特征 —— 跨图不变
├─ ⑤ 妆造层（可变）：妆容/服装 —— 随风格轮换
└─ ⑥ 状态层（可变）：姿势/表情/情绪 —— 随作品轮换
```

**铁律**：换风格换审美时只动 ⑤⑥；①②③④ 一个字不改，改了就是「换了个人」。
**防漂移写法**：①② 层「定位+否定」成对出现——既写「柔和鹅蛋脸」，也写「不是瓜子脸不是圆脸」。
**安全写法**：身材一律写「体态优雅匀称、比例协调、线条流畅」类整体印象；身份特征用服饰/发型/痣/酒窝等中性标志，不用身体数字。

## 三、组装公式

```
正向提示词 = [Pxx 前四层锚点原文粘贴] + [Fxx 风格骨架填 ⑤⑥ 可变层] + [Axx 审美词块] + [Uxx 用途规格]
→ 最后过一遍 S00 检查单再复制
```

**示例**：P02 银雾 × F02 广角透视 × A03 电影晨暮 × U01 头像
→ 「P02 的 ①②③④ 层原文 + F02 的机位句/三层纵深/焦点策略（姿势=窗边侧坐、表情=微垂眼睑）+ A03 晨暮光影词块 + 4:5 头像规格」

## 四、防漂移实战规则

1. **锚点前置**：模特描述永远放正向提示词最前面，位置=权重。
2. **双面写法最稳**：「是X不是Y」+ 整体印象词；避免一切数字身材参数（既防审核又防模型抽风）。
3. **第一识别符策略**：每人锁定一个最醒目的不变特征（P02 银发 / P04 眼镜 / P01 痣 / P03 酒窝），提示词里位置靠前+形容最细。
4. **跨图连续产出**（U05）：一份锚点合同配 4-6 个 ⑤⑥ 组合 = 一个小型写真系列；换 Fxx/Axx = 同一模特的不同企划。
5. **漂移急救**：出图脸变了 → 锚点被风格描述稀释（太短或被挤到后面）；身形变了 → 整体印象词被删或被风格词覆盖。
6. **一致性天花板**：纯文字锚点在同一次生成内最稳，跨次有漂移概率；要绝对一致走 ModelScope 参考图/图生图通道，文字锚点当第二层保险。
7. **登记录**：新模特按本模板六层建档追加到第二节，编号 Pxx 递增不回收；入档即过 S00 消毒。
