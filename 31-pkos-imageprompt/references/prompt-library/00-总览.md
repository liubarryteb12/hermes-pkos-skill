# 总览 · 五段命名题词体系 v4

> 对应网页：https://modelscope.cn/aigc/image-generation?tab=advanced（正向 Prompt + 负向 Negative Prompt 双框 + 出图参数面板）

## 体系全景

```
Pxx 模特资产（人） ─┐
Mxx 母题（画什么） ──┤
Sxx 子题（题材）    ├─→ 组装成正向/负向提示词 ──→ S00 安全层消毒 ──→ C00 参数面板 ──→ 出图
Fxx 风格（怎么画） ─┤
Axx 审美（什么气质）─┤
Uxx 用途（干什么用）─┘
```

**命名编号**：`Mxx-Sxx-Fxx-Uxx-Axx`（模特 Pxx 可选叠加，如 `P02 × M01-S03-F02-U01-A02`）

- **Pxx 模特**：固定人物锚点合同（骨架/面容/毛发/标志四层锁死，妆造状态两层轮换）
- **Mxx 母题**：内容大类 —— M01 人物写真 / M02 角色二次元 / M03 平面设计 / M04 幻想叙事
- **Sxx 子题**：母题下的题材细分
- **Fxx 风格**：出图的结构/技法流派（正向骨架+负向清单）
- **Uxx 用途**：画幅/细节密度/文字区/系列一致性
- **Axx 审美预设**：色彩秩序+光影+质感+情绪+英文质感词，一键换气质

## 出图前流程（每次必走）

1. **选题**：按检索逻辑选编号（想要什么气质→Axx；画什么→M/S；怎么画→F；干什么用→U；谁来当模特→P）
2. **组装**：Pxx 锚点前四层原文 + Fxx 骨架填 ⑤⑥ 层 + Axx 词块 + Uxx 规格 → 正向提示词
3. **消毒**：对照 **S00 安全层**过一遍（硬红线删除→字典替换→通读检查单），负向框同样过审
4. **参数**：按 **C00 参数规范**对号入座（分辨率行=画幅数字、Steps/CFG 按底模、Seed 工作流）
5. **出图**：探索期滚 seed → 满意锁 seed → 系列化

## 维护规则

- 新增任何维度：先登记对应 00 索引文件，编号递增不回收
- 同编号迭代：文件内升版本号，编号不变
- 冲突优先级：**S00 安全层 > A00 混血禁配 > 一切创意冲动**
- 提示词与参数的联查：塑料感查 CFG→磨皮词；构图崩查分辨率→提示词
