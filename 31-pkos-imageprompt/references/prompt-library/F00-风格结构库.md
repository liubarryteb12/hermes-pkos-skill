# F00 风格结构库（正向骨架 + 负向清单）

> 每个风格 = 一套可复用的结构骨架。使用时：骨架 + M/S 的题材变量 + Axx 审美词块 = 完整正向提示词。
> 负向清单按需取用；标注「通用底座」的任何风格都要带。

## F01 八段式结构流（长文工程流，最稳）

**正向骨架**：画幅 → 主体定位（年龄/人数/场景一句话）→ 人物表情（脸型五官发妆）→ 服装姿势 → 背景光线 → 构图镜头（机位/距离/焦点/虚化）→ 质感风格 → 【Axx 词块插入点】
**负面**：通用底座 + 该场景 1-2 个最易破绽（如旗袍件钉「不可省略立领与开衩」）
**适用**：S01-S05 全部子题；控制力最强，长度 300-800 字

## F02 广角透视流（张力写真的核心技法）

**正向骨架**：画幅 → 成年锚点 → 机位句（`镜头位于低位偏前侧，20-24mm 广角`）→ 透视描述（`近大远小：最近的主体元素进入极近前景并强烈放大，foreground enlargement + perspective exaggeration`）→ 其余部位后撤/扭转/foreshortening → 表情句 → **三层纵深**（前景身体→中景手臂→后景眼神）→ 焦点策略（前景 defocus、脸部锐利、不同时全锐）→ 服装材质英文词组 → 【Axx 词块】
**负面**：通用底座 + `腿部畸形，膝盖融合，比例失调，前景与面部同时模糊`
**适用**：S03 色气 / M02-S01 COS / 直播感

## F03 私房光影流（晨暮居家氛围核心）

**正向骨架**：画幅 → 成年锚点 → 单一光源定义（`晨光从窗帘缝隙斜射`）→ 明暗策略（高光带在肩颈锁骨腿，其余沉入阴影，电影感过渡）→ 姿态（床沿/窗边/躺卧，姿态松弛自然）→ 服装材质（缎面/棉麻+英文质感词）→ 空间生活痕迹（凌乱床单，非样板间）→ 氛围保险丝（`氛围来自姿态与光影，气质高级克制`）→ 【Axx 词块】
**负面**：通用底座 + `影棚布光，商业打光，过度HDR，样板间`
**适用**：S02 私房 / S03 色气

## F04 直闪抓拍流（CCD/胶片核心技法）

**正向骨架**：画幅 → 相机句（`disposable film camera` / `CCD digicam, soft-glow, highlight bloom` / `手机直闪`）→ 场景+人物短描述 → 闪光策略（正面直闪/环境暗/背景迅速变暗）→ 色盘三行公式 → 生活痕迹 → 【Axx 词块】
**负面**：通用底座 + `高清锐利，现代手机锐化，棚拍`
**适用**：S05 CCD复古 / S01 生活感

## F05 影棚极简流（商业质感核心）

**正向骨架**：画幅 → 成年锚点 → 无缝背景色（纯浅灰/深蓝灰）→ 无死角漫反射光+底部接触影 → 服装材质对撞（漆皮×薄纱）→ 肢体张力姿势（宽底座几何/躯干伸展）→ 【Axx 词块】
**负面**：通用底座 + `杂乱背景，环境道具，自然光`
**适用**：M02-S01 COS / S03 色气 / 新中式晚宴

## F06 设定图版式流（插画向版式）

**正向骨架**：`front-and-back character turnaround，同一角色正背并排，人物大小一致` → 纯白背景无场景 → 线稿规则（clean lineart 黑细描边，内部线极少）→ 上色规则（flat color dominant，soft cel shading 仅皮肤转折/衣褶）→ 比例规则（exaggerated hourglass 或标准）→ 服装设计信息（罗纹/麻花/镂空当结构而非光影）→ 【Axx 词块】
**负面**：通用底座 + `场景背景，环境光效，厚涂，真实摄影光影`
**适用**：M02-S03 Pin-up / 服装设计稿

## F07 版式机制流（海报平面核心）

**正向骨架**：画幅 9:16 → 【主题/标题/主体/版式机制/主色/强调色 填空】→ 版式律（`Typography 参与构图：巨大标题可出界/错位/被主体遮挡/压住主体`）→ 尺度反差（`巨大标题×强主体×极小信息字`）→ 单一冲突律（每张只建一个最强设计动作）→ 信息密度（局部集中不平均铺满）→ 色彩律（2-4 主色系+强调色爆点）→ 避免清单（`规则网格，卡片UI，PPT模块，对称，编号01/02，四角星芒，sparkle`）
**负面**：通用底座（去掉摄影类词）+ `模板感，无意义英文，随机乱码`
**适用**：M03-S01/S02；变体「磨砂玻璃」：三层结构（镜头—磨砂介质—角色）+ 大留白 + 5% 黄焦点

## F08 转绘分屏流（图生图核心，需上传照片）

**正向骨架**：六件套 = ①`3:4 竖版，上下严格 1:1 分屏` ②上半保留律（保留原图仅轻调色，可扩展环境不扭曲主体）③下半重构律（提取主体轮廓姿态叙事→转【材质】，一眼认出同一主体）④原图取色律（配色必须从原图分析产生）⑤文字融入律（短标题沿轮廓/轴线排列）⑥避免清单（卡通贴纸/塑料3D/廉价金边/模板感）
**材质库**：珐琅冰箱贴 / 金箔平面 / 治愈积木 / 厚涂微景观 / 剪纸 diorama
**负面**：`多图拼接，分屏错位，人脸走样，主体丢失，拉伸扭曲，文字乱码` + 通用底座
**适用**：M03-S03/S04

## 通用负向底座（所有摄影类风格必带）

```
低质量，模糊，畸形手指，多余手指，多余肢体，身体扭曲，面部扭曲，双头，比例失调，文字，水印，logo
```

二次元/平面类把 `卡通，动漫，插画` 从底座中删掉（它们是目标而非缺陷），换 `文字乱码，模板感`。
