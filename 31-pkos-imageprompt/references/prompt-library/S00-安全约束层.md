# S00 安全约束层（强制 · 所有可粘贴文本的最后一道工序）

> 背景：ModelScope 等平台对提示词做全文安全审核，正向框和负向框都查。
> 原则：**表达升维，不是藏词**——把「部位+尺度」的写法整体换成「光影+造型+构图+情绪」的写法，效果不丢，审核必过。
> 内部文件命名（如子题叫"色气"）无所谓，**凡是复制进 Prompt 框的每个字都要过本层字典**。

## 一、硬红线（看到即删，不重写不辩解）

1. 三围/罩杯等身体数字（94-58-92、F-to-G cup）
2. 部位聚焦+放大类描述（"臀胯占画面下半部""胸部体积"等）
3. 挑逗/欲望词族：sultry、seductive、teasing、provocative、性感、妩媚、诱惑
4. 恋物材质词组：sheer、see-through、透肤、nylon weave、denier 细节枚举
5. 舌头/唇部动作细节（舌尖若隐若现等）
6. 任何未成年暗示词（少女/学生+任何成人语境）；年龄锚点永远写「成年」+具体视觉年龄段
7. 负向框同样受审：负向里也不准出现"全裸/裸露"等禁词，用中性写法（见第四节）

## 三、结构性规则（比字典更重要）

1. **身材写整体印象与动态，不写部位与尺寸**：写"体态舒展/线条流畅/比例协调"，不写任何具体部位的经营。
2. **吸引力五杠杆换序**：光影 > 造型 > 构图 > 情绪 > 色彩——全部合法可写，够用了。
3. **成年锚点必写**：每条正向都含「成年」+视觉年龄段（如"二十多岁的成年女性"），这既是安全要求也是防幼态祖传手段。
4. **构图描述中性化**：机位/景深/焦点随便写，但别把"哪 individual 部位占画面多大"写进去。
5. **品牌/UI 植入全撤**：logo、签名、直播 UI 文字在多数模型上是乱码+审核双风险。

## 四、负向框安全写法

```
低质量，模糊，畸形手指，多余手指，多余肢体，身体扭曲，面部扭曲，双头，比例失调，儿童，文字，水印，logo，多人
```

想防"衣着不当"类翻车，用中性短语：`衣着不整，姿态不当`——不写任何具体违禁词。

## 五、被拦截后的三级降级策略

1. **一级·换词**：按第二节字典替换重发（结构不动）
2. **二级·降意象**：服装/场景降一档（睡裙→吊带裙；泡泡浴→窗边护发；泳装→沙滩时装）
3. **三级·纯氛围**：身材描述全删，只留光影/构图/情绪/造型——几乎不会失败

## 六、起飞前检查单（每次复制前 10 秒）

- [ ] 有数字身材参数吗？→ 删
- [ ] 有 sultry/teasing/性感词族吗？→ 换
- [ ] 有部位+画幅占比描述吗？→ 换成构图语言
- [ ] 写了「成年」+年龄段吗？→ 没写补上
- [ ] 负向框里有禁词吗？→ 换中性写法
- [ ] 通读一遍：这句话敢不敢当面念给陌生人听？→ 不敢就重写
