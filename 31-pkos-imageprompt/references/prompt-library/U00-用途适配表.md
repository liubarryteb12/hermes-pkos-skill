# U00 用途适配表

> Uxx 决定同一份提示词的输出规格：画幅、细节密度、文字量、出图策略。

## 用途注册表

| 编号 | 用途 | 画幅 | 细节密度 | 文字/水印 | 备注 |
|---|---|---|---|---|---|
| U01 | 社媒头像/贴图 | 1:1 或 4:5 | 中高 | 无文字 | 构图留头部余量，脸为主焦点 |
| U02 | 公众号/文章封面 | 2.35:1 或 16:9 | 中 | 可留标题负空间 | 主体偏一侧，另一侧留字位 |
| U03 | 短视频封面/竖屏内容 | 9:16 | 中 | 上 1/3 留字位 | 人物居中下，视觉重心稳 |
| U04 | 海报/打印展板 | 9:16 或 2:3 | 高 | 版式机制自带 | 配 F07/F08 使用 |
| U05 | 系列内容/IP 连续产出 | 统一画幅 | 高 | 系列标签固定 | 锁死人物锚点句+Axx，只变场景姿势 |
| U06 | 素材试验/审美探索 | 4:5 | 低 | 无 | 快出图，一句话骨架+换 Axx 扫气质 |
| U07 | 转绘/图生图 | 3:4 | 高 | 材质内置文字律 | 必须先上传照片 |

## 用途改写规则

1. **画幅一致律**：正向提示词里写的画幅 = 页面设置的出图比例 = Uxx 规定画幅，三处对齐。
2. **文字区预留**：U02/U03 要在正向里加一句「画面上侧/上三分之一保持简洁留白，供后期排版标题」。
3. **系列一致性**（U05）：把「人物锚点句」（脸型+发色+身材锚点+固定饰品）整理成固定段落，跨图不改；只轮换「姿势+场景+Axx 变量」。
4. **试验降本**（U06）：骨架砍到 100 字内，负向只留通用底座，一张图 30 秒出结果再决定是否精修。

## 常用组合速查

- 张力头像：M01-S03 + F02 + U01 + A02
- 生活感封面：M01-S01 + F01 + U02 + A01
- 居家光影系列：M01-S02 + F03 + U05 + A03（换 A04 即复古变体系列）
- COS 封面：M02-S01 + F02 + U03 + A02
- 文化海报：M03-S01 + F07 + U04 + A09
- 旅行转绘：M03-S03 + F08 + U07 + A10
- 银发清冷壁纸：M01-S03 + F02 + U03 + A05
