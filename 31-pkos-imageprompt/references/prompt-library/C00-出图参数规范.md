# C00 出图参数规范（ModelScope 高级模式通用）

> 提示词之外的第二半张答卷。取市面最通用的参数组：分辨率/步数/CFG/采样器/种子/批次。
> ModelScope 不同底模（SDXL / FLUX / SD3.5 / Qwen-Image 等）参数面板略有差异，按下表对号入座；没有的项跳过即可。

## 一、分辨率（画幅 × 像素，百万像素级通用档）

SDXL 系按 1024 基准，FLUX 系按 1MP-2MP 之间，Qwen-Image 支持更大。**选与提示词画幅数字一致的行**：

| 画幅 | 常用分辨率（宽×高） | 适用 |
|---|---|---|
| 1:1 | 1024×1024 | U01 头像 |
| 4:5 | 896×1152 | U01/U02 人像首选 |
| 2:3 | 832×1216 | U04 海报、全身像 |
| 3:4 | 880×1176（或 864×1152） | U07 转绘、八段式 |
| 9:16 | 768×1344 | U03 竖屏内容 |
| 16:9 | 1344×768 | U02 横封面 |
| 2.35:1 | 1536×640 | 电影感横幅封面 |

规则：**比例与提示词画幅数字必须一致**；不确定就 896×1152（人像）或 1024×1024，最不容易崩。

## 二、采样与步数

| 底模 | 采样器 | Steps | CFG | 备注 |
|---|---|---|---|---|
| SDXL / SD1.5 系 | DPM++ 2M Karras | 25-30 | 5-7 | CFG>8 易过饱和烤脸 |
| SDXL Turbo/Lightning | 任意 | 4-8 | 1-2 | 快速草稿用 U06 |
| FLUX 系 | Euler | 20-28 | 1（或引导档 2-3.5） | FLUX 基本不认负向框，负向留空 |
| SD3.5 | DPM++ 2M / Euler | 28-40 | 4-5 | |
| Qwen-Image 类 | 默认即可 | 20-50（默认） | 默认 | 按面板默认最稳 |

速记：**写实质感 = 步数 28-32 + CFG 4.5-6**；高 CFG 是"塑料感、烤糊脸"的第一元凶。

## 三、种子（Seed）工作流

- **探索期**：seed 随机（-1），先扫气质
- **锁定锚点**：出图满意 → 记下 seed → 微调提示词时**固定 seed**，只变文字，效果对比才成立
- **系列产出**（U05）：同一模特+同一 seed+换 ⑤⑥ 层=表情姿势自然成套
- **换抽不改稿**：结构对了脸不满意 → 固定提示词，只滚 seed；脸对了构图不满意 → 固定 seed 改构图词

## 四、批次与其他通用项

- **Batch count**：探索期 2-4 张/次，省时间；锁定后 1 张精调
- **Clip Skip**：SD 系 2（部分面板），FLUX 无此项
- **Hires fix / 放大**：先用小图定稿，再 1.5x 放大 + denoising 0.35-0.45（高了改构图，低了没细节）
- **负向提示词框**：SD 系必须填（用 S00 第四节安全底座）；FLUX 留空；Qwen 类填了也无害

## 五、按用途的推荐参数速查

| 用途 | 分辨率 | Steps/CFG | Seed 策略 |
|---|---|---|---|
| U01 头像 | 896×1152 | 30 / 5 | 定稿锁 seed |
| U02 封面 | 1344×768 | 30 / 5.5 | 横图脸部易崩，多抽 2 张 |
| U03 竖屏 | 768×1344 | 30 / 5 | 同上 |
| U04 海报 | 832×1216 | 32 / 5.5 | 文字类放大后重跑细节 |
| U05 系列 | 统一档 | 30 / 5 | 锚点句+固定 seed |
| U06 试验 | 1024×1024 | 8-25（加速器开） | 随机 |
| U07 转绘 | 880×1176 | 28 / 5 | 图生图 denoise 0.5-0.75 |

## 六、联查关系

- 提示词层（F00 骨架）→ 画幅数字 → 本表分辨率行 → Uxx 规格，四处一致
- 塑料感/烤脸 → 先查 CFG 是否 >7，再查提示词磨皮词
- 构图崩 → 先查分辨率是否偏离常用档，再查提示词
- 本文件与 S00 安全层并列：参数是"怎么出"，S00 是"出什么"
