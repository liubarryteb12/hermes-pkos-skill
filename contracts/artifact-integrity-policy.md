# 产物完整性契约（pkos-integrity:1）

> 所有产出落盘类单元（ingest/analysis/polish/router/exit）的写入防护通则。
> 版本：pkos-integrity 1 · 状态：已锁死（变更须 bump 并经评审）
> 来源：2026-08-26 公众号 239 篇批量任务的实战故障回流（B1 空 POL 覆盖 / B2 截断落盘）

## 为什么有这份契约

实战中发生过两起已确认的产物损毁，均无契约拦截：

- **B1 空 POL 覆盖好 POL**：`POL-…-02-01-20`（4260 字节好稿）被重试产生的 0 字节稿覆盖销毁——上游调用方无条件写盘。
- **B2 截断 HTML 落盘**：`01-04-10` 以 117 字残篇成为"交付物"（模型在 max_tokens 处截断）——无完整性断言即算完成。

本契约把防护从"脚本补丁"（gzh_pkos_pipeline.py）提升为**全单元通则**：任何 pkos 单元写入产物前必须执行下述两道门，不满足则拒绝落盘并按失败三态上报。

## 门 1：产物不回退（No-Retrograde Write）

**写入已存在文件前，必须比较新旧质量度量；新产物不达标则拒绝覆盖。**

| 产物类型 | 质量度量（按序判定） | 不达标时 |
|---|---|---|
| POL-* 净化稿 | ① 正文中文字数（剥 front matter/评分卡后）② 五维评分卡总分 | 保留旧稿，新稿写入 `.rejected/` 旁路并记 failure_mode |
| HTML 出口 | ① 中文字数 ② 禁止项计数（span leaf/违禁标签）③ 结构完整（含封面段+正文段+CTA） | 同上 |
| AN-* 发现表 | 发现条目数（0 条 = 无新发现，记 not_found 而非覆盖为空） | 同上 |
| RT-* 路由单 | 决策字段完整度（exit/conversion_type/theme/audience 四键齐全） | 同上 |
| 条目（entries） | 正文长度 + front matter 字段数 | 同上 |

**通则**：质量度量相同（差异 < 5%）时**不覆盖**（幂等保护，避免无意义写盘 churn）；**新稿严格更优**才允许覆盖。

**旁路规则**：被拒绝的新稿不丢弃，落 `<产物目录>/.rejected/<原名>-<时间戳>` 供人工复核——失败也有证据链（D-5 evidence 要求）。

## 门 2：完整性门槛（Integrity Gate）

**新产物（含首次落盘）必须通过完整性断言才算成功；不完整 = 失败三态上报，不算产出。**

| 断言 | 判定 | 失败归类 |
|---|---|---|
| 最小体量 | 正文中文字数 ≥ 该产物类型的下限（POL ≥ 400；HTML ≥ 400；AN ≥ 1 条发现；RT 四键齐全） | `unavailable`（生成源故障：截断/限流/空回包） |
| 结构完整 | HTML 必须含封面 section + ≥1 正文段 + CTA 尾段；截断特征检测（标签未闭合/句子中断） | `unavailable` |
| 哈希一致 | 落盘后重读计算 hash == 写入前内存 hash | `unavailable`（IO 故障） |
| 禁止项 | HTML 违禁标签计数 = 0（v0 验收清单沿用） | 失败重生成，重试 3 次仍违禁 → `unavailable` |

**重试边界**：完整性不达标允许重生成（含换 Provider），**同一产物最多 3 轮**；3 轮后仍不达标 → 上抛 `unavailable` + 全部尝试的证据链，**绝不以残篇充数**。

**与失败三态的映射**：
- 体量/结构/哈希不过 → `unavailable`（系统故障，不是"没找到目标"）
- KB 无对应素材导致的低质 → `not_found`（业务事实：素材缺口，走 B4 缺口标注，**不硬生成**）
- 多候选产物难取舍 → `ambiguous`（生成决策单，不自动选）

## 禁止事项（对齐 D-2 语义契约）

1. 禁止"写完就算成功"——落盘 ≠ 通过，过门才算。
2. 禁止覆盖时不比较——任何覆盖已存在产物的写入必须走门 1。
3. 禁止把截断/空回包静默记为成功。
4. 禁止在单元内私自放宽门槛——门槛参数属于本契约，单元只引用不定义。

## 单元接入方式

各单元 SKILL.md 的 v2 契约段（C-3 outputs / C-4 failures）引用本契约：

```yaml
outputs:
  integrity_policy: "contracts/artifact-integrity-policy.md"   # 门 1 + 门 2 生效
```

门参数（体量下限等）以本契约为唯一事实源；单元私有参数（如 HTML 禁止项清单沿用 gzh 验收）在单元内声明并指向本契约兜底。

## 验收断言（本契约自身的回归用例）

- 空 POL（< 200 中文字）尝试覆盖 4 KB 好 POL → 拒绝，旧稿完好，新稿在 `.rejected/`
- 截断 HTML（117 字）首次落盘 → 拒绝，重试流水启动，3 轮后仍残 → `unavailable` 上抛
- 相同质量（差异 < 5%）重复生成 → 不覆盖（幂等）
- KB 无素材主题 → `not_found` + 缺口标注，不静默生成
